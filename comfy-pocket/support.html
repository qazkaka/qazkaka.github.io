Questions about using the app and bug reports are welcome. Please check the FAQ below first.

Getting started

  1. Start ComfyUI on your PC and make it reachable from your iPhone. On the same Wi-Fi, start ComfyUI with --listen 0.0.0.0 and allow its port (usually 8188) in your PC's firewall.
  2. In the app, add a server, enter http://YOUR-PC-IP:8188, and test the connection.
  3. Import a workflow JSON exported with ComfyUI's “Export (API)”, or add one from the samples.
  4. Open the workflow, fill in the fields, and tap Run.

FAQ

I can't connect

Make sure your iPhone and PC are on the same network. Guest Wi-Fi often blocks devices from talking to each other. In iPhone Settings → Privacy & Security → Local Network, allow Comfy Pocket.

I want to use it away from home

Use a VPN such as Tailscale, or an HTTPS reverse proxy. If you expose ComfyUI to the internet, always set up authentication. The app supports Bearer token authentication.

The app says the server is missing required nodes

The workflow uses custom nodes or models that aren't installed in the ComfyUI you're connected to. Install them in ComfyUI and run again.

Does the app generate images with AI?

No. All generation happens on the ComfyUI servers you add. Install the models and custom nodes you need in ComfyUI.

Is the app available in English?

The app's interface is currently in Japanese. Workflows, prompts and results work in any language.

Managing files on your PC (optional)

In a server's file management settings, you can list ComfyUI's outputs and input images. To list your PC's folders directly and delete files, install the custom node comfy-pocket-files in ComfyUI's custom_nodes folder and restart ComfyUI.

cd ComfyUI/custom_nodes
git clone https://github.com/qazkaka/comfy-pocket-files.git

Deleting files on your PC is disabled by default. To allow it, create config.json in the node's folder containing {"allow_delete": true}.

Anyone who can reach your ComfyUI can list your files, and can delete them if deletion is allowed. If you expose ComfyUI to the internet, always set up authentication.
