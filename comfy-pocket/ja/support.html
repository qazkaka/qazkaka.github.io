お問い合わせ

✉︎ メールで問い合わせる

不具合のご報告では、端末の機種とiOSのバージョン、アプリのバージョン、ComfyUIの接続方法（同じWi-Fi・VPNなど）をお書き添えください。

はじめに

  1. PCでComfyUIを起動し、iPhoneから届くようにします。同じWi-Fiで使う場合は、ComfyUIの起動オプションに --listen 0.0.0.0 を付け、PCのファイアウォールでポート（通常8188）を許可します。
  2. アプリの「サーバーを追加」で http://PCのIPアドレス:8188 を入力し、「接続をテスト」を押します。
  3. ComfyUIの「Export (API)」で書き出したワークフローのJSONを取り込むか、「サンプルから追加」を使います。
  4. ワークフローを開いて入力し、「実行」を押します。

よくある質問

接続できません

iPhoneとPCが同じネットワークにあるか確認してください。ゲストWi-Fiでは端末どうしの通信ができないことがあります。iPhoneの「設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で、Comfy Pocketを許可してください。

外出先から使いたい

TailscaleなどのVPNや、HTTPSのリバースプロキシを使ってください。インターネットに公開する場合は、必ず認証を設定してください。アプリはBearerトークンによる認証に対応しています。

「接続先に必要なノードがありません」と表示されます

ワークフローが使っているカスタムノードやモデルが、接続先のComfyUIに入っていません。ComfyUI側で導入してから、もう一度実行してください。

アプリはAIで画像を生成しますか

いいえ。生成はすべて、登録したComfyUIのサーバーで行います。使うモデルやカスタムノードは、ComfyUI側で用意してください。

PCのファイルを管理する（任意）

サーバー設定の「ファイル管理」で、ComfyUIの出力・入力画像の一覧を表示できます。PCのフォルダーを直接一覧にしたり削除したりするには、拡張ノード comfy-pocket-files をComfyUIの custom_nodes フォルダーに入れて、ComfyUIを再起動してください。

cd ComfyUI/custom_nodes
git clone https://github.com/qazkaka/comfy-pocket-files.git

PCのファイルの削除は、初期状態では無効です。使う場合は、拡張ノードのフォルダーに config.json を作り、{"allow_delete": true} と書いてください。

ComfyUIに接続できる人は誰でもファイルを一覧でき、削除を許可していれば削除もできます。インターネットに公開する場合は、必ず認証を設定してください。

Comfy PocketはComfyUIに対応した非公式のクライアントです。ComfyUIの開発元とは関係ありません。
