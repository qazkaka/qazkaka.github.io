よくある質問

機種変更のとき、データを移すには？

元の端末で「設定 → データ → コレクションを書き出す」からバックアップファイルを保存し、新しい端末の「設定 → データ → バックアップを読み込む」で読み込みます。写真・使用記録・入力候補・保存した絞り込み条件も移ります。

ものクログ Proで「iCloudに自動でバックアップ」をオンにしている場合は、新しい端末の「設定 → iCloudバックアップ → iCloudのバックアップから復元」から読み込めます。

バックアップを読み込むと、今のデータはどうなりますか？

まだ登録していない商品は追加されます。すでに登録済みの商品が含まれる場合は、「未登録の商品だけ追加」か「登録済みの商品も上書き」を選べます。上書きは取り消せないため、必要なら先に現在のデータを書き出してください。

iCloudの自動バックアップはどこに保存されますか？

お使いのApple AccountのiCloud Driveに保存され、「ファイル」アプリの「iCloud Drive → ものクログ」から確認できます。最新の5件を残し、古いものは自動で削除します。iCloudの容量を使用します。

Proを購入したのに有効になりません／機種変更でProを戻したい

「設定 → ものクログ Pro → 購入を復元」をお試しください。購入時と同じApple Accountでサインインしている必要があります。購入は買い切りで、月額料金はかかりません。

無料版でいくつまで登録できますか？

持っている物・欲しい物・手放した物の合計で10件まで登録できます。上限に達した後も、登録済みの商品の閲覧・編集・使用記録・バックアップは引き続き使えます。

発売日の通知が届きません

iPhoneの「設定 → 通知 → ものクログ」で通知が許可されているかご確認ください。発売時刻を登録していない商品は、発売日の9:00を基準に通知します。

「データを読み込めませんでした」と表示されます

保存されているデータは削除されていません。まず端末を再起動し、「もう一度試す」をお試しください。解決しない場合は、同じ画面の「データファイルを書き出す」でファイルを保存したうえで、メールでご連絡ください。

データをすべて削除したい

iPhoneでアプリを削除すると、端末内のデータはすべて削除されます。書き出したバックアップファイルやiCloud Driveのバックアップは、それぞれ保存先から削除してください。

不適切な広告を見かけました

「設定 → プライバシー → 不適切な広告を報告」からご報告ください。ものクログ Proでは広告は表示されません。
