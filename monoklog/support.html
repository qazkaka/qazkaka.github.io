お問い合わせ

✉︎ メールで問い合わせる

不具合のご報告では、お使いの端末・iOSのバージョン・アプリのバージョン（「設定」の一番下に表示）と、起きたときの操作を添えていただくと、調査がスムーズです。写真やバックアップファイルは、こちらからお願いした場合を除き送らないでください。

グループの不適切な投稿・利用者の報告1.5〜

グループで、不快・不適切な投稿やコメント、嫌がらせをする利用者を見かけた場合は、アプリから通報してください。投稿は長押し（または「…」）、コメントとメンバーは「…」から「通報する」を選びます。通報したことは、相手やほかのメンバーには知らされません。

内容を確認し、利用規約に反している場合は、その利用者を利用停止にします。利用停止になった人の投稿はほかの利用者に表示されず、グループにも参加できなくなります。急ぎの場合や、通報で伝えきれない場合はメールでご連絡ください。

不適切な広告の報告

無料版で表示される広告に、不快・不適切な内容や、誤解を招く内容がありましたらお知らせください。内容を確認し、該当する広告や広告主の表示を停止します。

✉︎ メールで広告を報告する

次の情報を添えていただくと、特定がスムーズです。

  • 広告の内容（広告主名・表示された文言など）
  • 表示された画面（コレクション・欲しい物・タイムライン・統計・設定）
  • 表示された日時
  • 可能であれば、広告が写ったスクリーンショット

ものクログ Proでは広告は表示されません。

よくある質問

グループ

グループとは何ですか？1.5〜

招待した人どうしで、コレクションに加えた物・欲しい物・使った記録をタイムラインで見せ合える機能です。投稿には、いいねやコメントができます。グループを作るにはものクログ Proが必要で、招待されたグループへの参加は無料です。1つのグループは10人まで、参加できるグループは作ったもの・申請中を含めて5つまでです。iCloudへのサインインが必要です。

グループに参加するには？1.5〜

グループのリーダーから届いた招待リンクを開き、表示名を決めて「申請」します。リーダーが承認すると参加でき、投稿が見られるようになります。招待リンクを受け取っている場合は、「タイムライン」左上のグループのボタン → 「招待リンクから参加する」から貼り付けることもできます。

招待リンクを開いても参加できません1.5〜

次の点をご確認ください。

  • 招待リンクは作ってから24時間有効です。期限が切れたときや、リーダーが受付を締め切ったときは、新しいリンクをリーダーに作ってもらってください。
  • iPhoneの「設定」でiCloudにサインインしているか。
  • グループがすでに10人になっていないか、あなたの参加しているグループが5つになっていないか。
  • 申請のあとは、リーダーの承認を待つ必要があります。承認されると通知でお知らせします。

グループに投稿した内容は誰が見られますか？1.5〜

そのグループのメンバーだけです。投稿・いいね・コメントは、書いた人自身のiCloudに保存し、Appleの共有の仕組みでメンバーだけが読めるようにしています。開発者が内容を見ることはありません。Apple Accountの名前やメールアドレスは、ほかのメンバーに伝わりません。価格・メモ・保管場所など、投稿に載せていない情報は共有されません。

相手をブロックしたい／ブロックを解除したい1.5〜

投稿やコメントの「…」、またはグループのメンバーの「…」から「この人をブロック」を選びます。ブロックした人の投稿とコメントは、あなたのアプリに表示されなくなります。相手には知らされません。解除は「タイムライン」左上のグループのボタン → 「グループの設定」 → ブロックしている人の「解除」から行えます。

自分の投稿やコメントを消したい／グループから抜けたい1.5〜

自分の投稿は長押し（または詳細画面の「…」）から「投稿を削除」、コメントは「…」から「コメントを削除」で消せます。グループから抜けるには、グループの画面の一番下にある「グループから抜ける」を選びます。抜けると、そのグループにあるあなたの投稿・いいね・コメントは削除されます。リーダーは「グループを解散する」を選べます。解散すると、すべてのメンバーがそのグループを見られなくなります。

グループの写真が消えました1.5〜

グループに投稿した写真は、投稿した人が「グループの設定」で選んだ保存期間（30日・90日・1年・無期限。初期設定は1年）を過ぎると自動で削除されます。投稿の文字は残ります。お手元のコレクションの写真は削除されません。

グループのお知らせを止めたい1.5〜

「タイムライン」左上のグループのボタン → 「グループの設定」で「新しい投稿・申請を通知」をオフにします。お知らせには、投稿の本文や写真は表示されません。

リーダーがProをやめたら、グループはどうなりますか？1.5〜

リーダーのProが有効でなくなると、グループは閉鎖され、投稿は表示されなくなります（データは残っています）。メンバーは、閉鎖中もグループから抜けることができます。リーダーがProを購入し直すと、グループは再開します。リーダーは、閉鎖される前に「リーダーを任せる」で、ほかのメンバーにリーダーを交代することもできます。

そのほか

機種変更のとき、データを移すには？

元の端末で「設定 → データ → コレクションを書き出す」からバックアップファイルを保存し、新しい端末の「設定 → データ → バックアップを読み込む」で読み込みます。写真・使用記録・入力候補・保存した絞り込み条件も移ります。

ものクログ Proで「iCloudに自動でバックアップ」をオンにしている場合は、新しい端末の「設定 → iCloudバックアップ → iCloudのバックアップから復元」から読み込めます。

バックアップを読み込むと、今のデータはどうなりますか？

まだ登録していない商品は追加されます。すでに登録済みの商品が含まれる場合は、「未登録の商品だけ追加」か「登録済みの商品も上書き」を選べます。上書きは取り消せないため、必要なら先に現在のデータを書き出してください。

iCloudの自動バックアップはどこに保存されますか？

お使いのApple AccountのiCloud Driveに保存され、「ファイル」アプリの「iCloud Drive → ものクログ」から確認できます。最新の5件を残し、古いものは自動で削除します。iCloudの容量を使用します。

Proを購入したのに有効になりません／機種変更でProを戻したい

「設定 → ものクログ Pro → 購入を復元」をお試しください。購入時と同じApple Accountでサインインしている必要があります。購入は買い切りで、月額料金はかかりません。

無料版でいくつまで登録できますか？

持っている物・欲しい物・手放した物の合計で10件まで登録できます。上限に達した後も、登録済みの商品の閲覧・編集・使用記録・バックアップは引き続き使えます。

発売日の通知が届きません

iPhoneの「設定 → 通知 → ものクログ」で通知が許可されているかご確認ください。発売時刻を登録していない商品は、発売日の9:00を基準に通知します。

「データを読み込めませんでした」と表示されます

保存されているデータは削除されていません。まず端末を再起動し、「もう一度試す」をお試しください。解決しない場合は、同じ画面の「データファイルを書き出す」でファイルを保存したうえで、メールでご連絡ください。

データをすべて削除したい

iPhoneでアプリを削除すると、端末内のデータはすべて削除されます。書き出したバックアップファイルやiCloud Driveのバックアップは、それぞれ保存先から削除してください。

不適切な広告を見かけました

アプリの「設定 → プライバシー → 不適切な広告を報告」、またはこのページの不適切な広告の報告からメールでご報告ください。ものクログ Proでは広告は表示されません。

シリーズはどこで登録しますか？1.3〜

商品の編集画面で「メーカー・ブランド」を選ぶと、その下の「シリーズ」で選べます（例：NIKE › エア ジョーダン）。シリーズの候補は「設定 → 入力候補の管理 → ブランド・メーカー」でブランドをタップすると、追加・名前の変更・削除ができます。ブランドを変えると、シリーズは外れます。

ブランドやシリーズごとに一覧で見たい1.3〜

「コレクション」上部の「カテゴリ」を開き、メーカー・ブランドをタップするとシリーズが並びます。シリーズをタップすると、そのシリーズの商品を写真で並べた画面になり、よく使う順・最近使った順などに並べ替えられます。右上のボタンから、いつもの一覧で表示することもできます。

型番やメモをコピーしたい1.3〜

商品の詳細画面で、商品名・登録情報の値・メモを長押しすると、範囲を選んでコピーできます。

アプリの色を変えたい

「設定 → 表示 → 外観」で「端末に合わせる／ライト／ダーク」を選べます。ものクログ Proでは「カスタム」を選び、背景・カード・文字・アクセントの色を自由に設定できます。
